PHASE 0 — SYSTEM FOUNDATION (CRITICAL THINKING FIRST)
Goal:

Define what the system is before coding anything

Step 0.1: Define Core Domain (VERY IMPORTANT)

You must formalize these core domain objects:

User
Wallet (multi-currency)
Collection (group)
Expense / Bill
Split Rule
Transaction
Notification

These map directly to your FYP scope:

Collaborative finance
Multi-currency
Hybrid split logic

Step 0.2: Define Bounded Contexts (Microservices)

Split system into independent domains:

Microservice	Responsibility
Auth Service	Authentication & JWT
User Service	Profile, Payee
Wallet Service	Multi-currency balances
Collection Service	Group management
Split Service	Core algorithm engine
Transaction Service	Payment execution
FX Service	Currency conversion
Notification Service	Async messaging

Principle:
Single Responsibility + Low Coupling + High Cohesion

Step 0.3: Define Data Ownership (Database per Service)

Each service MUST own its own database:

Wallet DB ≠ Collection DB
No shared tables

This ensures:

Fault isolation
Scalability
Data integrity
